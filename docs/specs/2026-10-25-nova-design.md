# Nova – дизайн и архитектура

Дата: 2026-10-25  
Статус: реализовано для Windows; Android ждёт отдельной команды.
Основа: направление **B · Sonora**, имя **Nova**, иконка – «тающий колокол».

Актуальные источники поиска: Zaycev.net, Muzofond.fm, DriveMusic.me. Deezer остаётся для импорта плейлистов, YouTube и Яндекс Музыка – для импорта. Тексты песен – Genius.

## 1. Зачем

Локальная музыка лежит в папках, но нормального плеера, который принимает эту реальность, нет. Nova – личная фонотека: она читает папки на месте, собирает альбомы и плейлисты поверх папок, запоминает, где вы остановились, и умеет добирать музыку из ссылок и по названию.

**Для кого:** один слушатель с собственной коллекцией на Windows; позже – на Android.

**Главный сценарий:** открыть приложение → увидеть последнюю песню и очередь → нажать play → листать треки, менять громкость, перемешивать, ставить повтор → уйти в плейлист или избранное.

## 2. Цели и не-цели

### Цели

- Читать локальные папки без копирования файлов в приложение.
- Сканировать при запуске и вручную; показывать новые треки.
- Плейлисты, которые комбинируют треки из разных папок.
- Избранное как отдельный «альбом».
- Очередь с видимым порядком после перемешивания.
- Воспроизведение: play/pause, next/prev, seek, громкость, повтор одного трека, повтор очереди.
- Эквалайзер с пресетами и своими пресетами.
- Сортировка: A–Z, по названию, по исполнителю, по альбому, по дате добавления.
- Обложки: из тегов, иначе из имени файла/папки; ручная замена обложки.
- Фоны: приложения и экрана «сейчас играет» – пользовательские картинки.
- Импорт ссылок плейлистов, поиск и загрузка после подтверждения.
- Распознавание трека: встроенное + AudD/ACRCloud по ключу.
- Восстановление последней очереди и последнего трека при запуске.
- Android: фон, audio focus, внешние аудио/видео, медиа-уведомление.

### Не-цели первой версии

- Стриминг по подписке и обход DRM.
- Социальная сеть, рекомендации, радио.
- Синхронизация между устройствами.
- Редактор тегов (кроме обложки) – можно добавить позже.
- Видео-плеер.

### Анти-цели

- Приложение не удаляет файлы пользователя.
- Приложение не скачивает ничего без подтверждения.
- Приложение не отправляет библиотеку на сервер.

## 3. Подходы

| Подход | Что даёт | Чем платим | Решение |
|--------|----------|------------|---------|
| **A. Web Audio + asset protocol** (desktop) | быстрый UI, эквалайзер через BiquadFilter, один код с Android UI | фоновое аудио на Android требует нативного слоя | **выбран для Windows** |
| **B. Нативный Rust-аудиодвижок (rodio/cpal)** | полный контроль, фон | сложнее синхронизация с UI и EQ, два движка | отклонён для MVP |
| **C. Нативный ExoPlayer на обеих платформах** | идеальный Android-фон | на Windows тянет лишний слой и не даёт Web Audio EQ | **выбран для Android** |

Итог: **общий React-интерфейс, два аудиодвижка**. Windows – HTMLAudioElement + Web Audio; Android – Kotlin-плагин с ExoPlayer и MediaSession. Интерфейс одинаковый, мост команд одинаковый.

## 4. Визуальное направление

Основа – `docs/design/mockups/b-nocturne.html`.

- Фон `#0B0B0D`, панель `#131316`, линия `#24242A`.
- Текст `#F1EEE7`, вторичный `#9B968C`, третичный `#6E6A63`.
- Акцент `#D9A441` (янтарь), на акценте – тёмный текст `#17130A`.
- Дисплейная гарнитура: **Playfair Display** (кириллица), UI: **Manrope** (кириллица). Обе кладутся в сборку, без сети.
- Радиусы: 4–8 px у панелей, 50% у круглых кнопок. Без градиентов, стекла и теней в покое.
- Обложки – главный визуальный объект. Большая обложка на главной, 34–58 px в списках.
- Плеер всегда внизу, 96 px; на мобильном – 72 px + мини-плеер.
- Иконка: «тающий колокол» – мягкие дуги, каплевидный низ, янтарная капля. Фон `#26262B`, глиф `#E8E8EA`, акцент `#E3A857`.

### Экраны

1. **Главная** – «Добрый вечер», продолжить слушать, недавно добавленные, плейлисты, очередь.
2. **Библиотека** – вкладки «Треки / Альбомы / Папки / Плейлисты / Избранное», сортировка, поиск.
3. **Альбом** – обложка, список треков, «убрать из альбома» (скрыть), «играть всё».
4. **Плейлист** – обложка-мозаика, треки, перетаскивание порядка, «играть всё», «перемешать».
5. **Избранное** – автоматический альбом; сердца из любого места.
6. **Сейчас играет** – большой экран: обложка, фон, очередь, эквалайзер, повтор.
7. **Очередь** – порядок, текущий трек, перетаскивание, «перемешать заново».
8. **Импорт** – вставить ссылку, разобрать, список треков с галочками, «скачать выбранные/все».
9. **Распознать** – микрофон или системный звук, запись 12 секунд, результат, «найти и скачать».
10. **Загрузки** – активные и завершённые, прогресс, папка назначения.
11. **Настройки** – папки, автосканирование, источники поиска, yt-dlp, Shazam-ключ, эквалайзер, фоны, скрытые треки, хранилище.
12. **Эквалайзер** – 10 полос, пресеты, свои пресеты, предусиление.

## 5. Данные

SQLite в `appDataDir/nova.db`. Схема:

```sql
folders(id, path, recursive, added_at, last_scan_at)
tracks(id, path UNIQUE, folder_id, filename, title, artist, album, album_artist,
       track_no, year, genre, duration_ms, size, mtime, format, bitrate,
       cover_path, custom_cover_path, added_at, updated_at)
playlists(id, name, description, cover_path, created_at, updated_at, sort_order)
playlist_items(id, playlist_id, track_id, position, added_at)
favorites(track_id PRIMARY KEY, added_at)
hidden_tracks(track_id PRIMARY KEY, hidden_at, reason)
settings(key PRIMARY KEY, value)
queue_state(id=1, context_type, context_id, track_ids_json, current_index,
            position_ms, shuffle, repeat_mode, updated_at)
eq_presets(id, name, bands_json, preamp, builtin, created_at, updated_at)
downloads(id, url, source, title, artist, status, progress, file_path,
          error, created_at, finished_at)
import_jobs(id, source, url, raw_json, created_at)
```

- `tracks.path` – абсолютный путь, уникальный ключ.
- `hidden_tracks` – трек скрыт из альбома/библиотеки, файл остаётся.
- `favorites` – виртуальный альбом «Избранное».
- `queue_state` – одна строка, восстанавливается при старте.
- `settings` – JSON-значения: `music_folders`, `auto_scan`, `theme`, `app_background`, `now_playing_background`, `ytdlp_path`, `shazam_provider`, `shazam_key`, `search_sources`, `volume`, `eq_active_preset`, `sort_mode`.

## 6. Сканирование

- При старте: если `auto_scan=true`, фоновый скан всех папок.
- Вручную: кнопка «Сканировать» на главной/в настройках; прогресс через Tauri events.
- Рекурсивный обход (`walkdir`), расширения: mp3, flac, wav, ogg, opus, m4a, aac, wma, aiff.
- Метаданные: `lofty`. Если тегов нет – `Artist - Title` из имени файла; альбом – имя папки; исполнитель – «Неизвестный исполнитель».
- Обложка: встроенная в тег → `covers/<sha1(path)>.jpg`; иначе ищем `cover.jpg`, `folder.jpg`, `front.jpg` в папке; иначе плейсхолдер с инициалами.
- Инкрементальность: сравниваем `mtime + size`; если не изменилось – пропускаем.
- Удалённые файлы: помечаем `missing=1` (добавить колонку) и скрываем из списков; файл не трогаем. При возврате файла – `missing=0`.
- Скрытые треки не возвращаются автоматически. В настройках – «Скрытые треки» → «Восстановить».
- Новые треки: после скана показываем счётчик «Добавлено N» и фильтр «Недавно добавленные».

## 7. Плеер и очередь

- Контекст воспроизведения: альбом, плейлист, избранное, папка, результаты поиска, очередь.
- `playContext(trackIds, startIndex)` создаёт очередь.
- Shuffle: генерирует новый массив `queue.order` из текущего контекста, сохраняет `currentIndex` на первый трек; показывает порядок в панели очереди. Повторное нажатие выключает shuffle и возвращает исходный порядок (исходный массив хранится рядом).
- Repeat: `off | one | all`. «Повтор одного» зацикливает текущий трек; кнопка визуально активна.
- Next/prev: по текущему порядку; при repeat all – по кругу.
- Громкость: 0–100, mute, сохраняется.
- Позиция: сохраняется каждые 5 секунд и при паузе/закрытии.
- Last session: при запуске восстанавливаем очередь, трек и позицию, но **не запускаем автовоспроизведение** – показываем «Продолжить» на главной и в плеере. Это защита от неожиданного звука. (Если нужно автозапуск – переключатель в настройках.)
- Медиа-клавиши Windows: через `global-shortcut` или нативный плагин? Tauri global shortcut не ловит мультимедиа-клавиши надёжно. MVP: кнопки в приложении; позже – нативный хук. В спеке отмечаем как риск.

## 8. Эквалайзер

- 10 полос: 31, 62, 125, 250, 500, 1k, 2k, 4k, 8k, 16k Гц.
- Web Audio: цепочка `MediaElementSource → preamp GainNode → 10 × BiquadFilter(peaking) → GainNode → destination`.
- Диапазон −12…+12 дБ, Q ≈ 1.1.
- Встроенные пресеты: Flat, Bass, Vocal, Rock, Pop, Classical, Night, Warm.
- Свои пресеты: имя + 10 значений + preamp; хранятся в `eq_presets`; можно редактировать/удалять.
- При смене трека цепочка не пересоздаётся; при смене аудио-элемента – пересоздаётся.
- На Android EQ переносится в ExoPlayer `Equalizer`/`BassBoost` (системный API) или в нативный DSP; список полос может отличаться. Это ограничение фиксируем в UI.

## 9. Импорт ссылок и загрузка

### Импорт

- Вставка ссылки → определение источника:
  - **YouTube / YouTube Music** – `yt-dlp --flat-playlist --dump-single-json` (надёжно).
  - **Deezer** – публичный API.
  - **Apple Music** – разбор публичной страницы.
  - **Spotify** – Web API с Client ID/Secret из настроек; без ключей – только название плейлиста и предупреждение.
  - **Яндекс Музыка / VK** – публичная страница, best-effort; при неудаче – ручной список.
- Результат: `ImportTrack { title, artist, album, duration, sourceUrl }`.
- Экран подтверждения: таблица с галочками, «выбрать все», «снять все», поиск по списку.
- Для каждого выбранного трека: поиск в yt-dlp (`ytsearch5:artist title`), показ кандидатов (title, duration, channel), выбор лучшего автоматически + возможность заменить.
- Скачивание: `yt-dlp -f bestaudio -x --audio-format m4a` (без ffmpeg) в папку `Downloads` (по умолчанию) или в выбранную. Метаданные и обложка – `--embed-metadata --embed-thumbnail` (для m4a работает).
- Прогресс: парсим stdout `[download] 42.3%`; events в UI.
- После завершения – добавляем файл в индекс и показываем «Добавлено в библиотеку».

### yt-dlp

- Sidecar `yt-dlp.exe` в `src-tauri/binaries/`, версия фиксируется в `docs/DECISIONS.md`; обновление – кнопка в настройках (скачать последнюю версию).
- Запуск только через `tauri-plugin-shell`/Rust `Command` с массивом аргументов, без `shell: true`.
- Настройки: путь к yt-dlp, папка загрузок, формат (m4a/mp3), качество, встраивать обложку.
- Юридическое: пользователь подтверждает, что имеет права на скачивание. Приложение не обходит DRM; для Spotify/Apple доступны только метаданные.

### Поиск по названию и автору

- Поле «Найти и скачать»: `artist + title`.
- Провайдеры: iTunes Search API, Deezer API, MusicBrainz (метаданные); yt-dlp (аудио).
- Результаты: обложка, название, исполнитель, альбом, длительность, источник, кнопка «Скачать».
- Пользовательские источники в настройках: `{ name, searchUrl, note }`; открываются в браузере или передаются в yt-dlp, если это поддерживаемый URL.

## 10. Shazam / распознавание

Два провайдера, переключатель в настройках:

1. **Встроенный Shazam-совместимый** – запись 12 секунд, генерация подписи, запрос к `amp.shazam.com`. Без ключа. Может сломаться при изменениях; при ошибке предлагаем ручной поиск.
2. **AudD / ACRCloud** – запись, отправка на API с ключом пользователя; стабильнее и легальнее. Ключ хранится в настройках (не в git).
3. **Ручной поиск** – всегда доступен: ввести «исполнитель – название».

Результат: название, исполнитель, альбом, обложка, кнопки «Найти в библиотеке», «Найти и скачать», «Открыть источник». Микрофон – только по нажатию, с индикатором записи; разрешение запрашивается один раз.

## 11. Кастомизация

- Обложка трека: «Заменить обложку» → выбор файла → копия в `covers/custom/<track_id>.<ext>` → `custom_cover_path`. Сброс – «Вернуть исходную».
- Фон приложения: настройки → выбор изображения → копия в `backgrounds/app.<ext>`; CSS `background-image` с затемнением 40–60% для читаемости.
- Фон экрана «сейчас играет»: отдельное изображение; если не задано – размытая обложка? Размытие – это фильтр, не градиент; допустимо, но лучше плоский тёмный фон + обложка. Используем затемнённое изображение или обложку с overlay.
- Прозрачность/затемнение фона – слайдер 0–80%.
- Всё хранится локально; при удалении файла фона – сброс.

## 12. Android (этап 2)

- Tauri 2 mobile + Kotlin-плагин `NovaAudio`.
- ExoPlayer + `MediaSessionService` + foreground service `mediaPlayback`.
- `AudioManager.requestAudioFocus` с `AUDIOFOCUS_GAIN`; при `AUDIOFOCUS_LOSS`/`LOSS_TRANSIENT` – пауза; при `GAIN` – возобновление, если пауза была автоматической.
- Уведомление: обложка, play/pause, next/prev, seek.
- Внешние интенты: `ACTION_VIEW` для `audio/*` и `video/*`; при запуске внешнего файла – пауза; после завершения/выключения – возобновление. Регистрируем `intent-filter` в `AndroidManifest.xml`.
- Папки: SAF (`ACTION_OPEN_DOCUMENT_TREE`), persistable URI permission; сканирование через `DocumentFile`. Пути content:// хранятся отдельно; ExoPlayer играет по URI.
- Скачивание: yt-dlp на Android не поставляем; прямые URL и серверный источник. Обсуждаемо позже.
- Сборка: `npm run tauri android build`; APK/AAB; проверка на эмуляторе и устройстве.
- С этого этапа **каждое изменение проверяется на Windows и Android**.

## 13. Технический стек

- Tauri 2, Rust stable MSVC.
- React 19 + TypeScript + Vite.
- Zustand для состояния; React Router для экранов.
- CSS: глобальные токены + CSS-модули/скоуп; без UI-кита, чтобы сохранить характер B.
- `lucide-react` для иконок интерфейса.
- Rust: `rusqlite` (bundled), `lofty`, `walkdir`, `serde`, `serde_json`, `reqwest`, `sha1`, `image`, `tauri-plugin-dialog`, `tauri-plugin-shell`, `tauri-plugin-opener`, `tauri-plugin-store` (если нужно).
- Тесты: Rust unit для сканера/БД/плейлистов; Vitest для чистых функций (сортировка, shuffle, repeat, форматирование); Playwright для веб-макетов; Windows-приложение проверяем через `windows-vision` + UI Automation.

## 15. Критерии готовности десктопа

- При запуске сканирует `Music/`, показывает 4 трека, обложки, длительности.
- Играет mp3, пауза/продолжение, seek, громкость.
- Shuffle меняет порядок в очереди и показывает его; repeat one зацикливает.
- Плейлист «Ночная смена» собирает треки из разных папок (после добавления второй папки).
- Сердце добавляет в «Избранное»; «убрать из альбома» скрывает трек, файл остаётся.
- Эквалайзер меняет звук; пресет сохраняется.
- Перезапуск восстанавливает очередь и трек (пауза).
- Импорт ссылки показывает список и скачивает выбранные.
- Распознавание возвращает трек и предлагает скачать.
- Нет сетевых запросов без действия пользователя.

## 16. Риски

- **Spotify/Apple/Яндекс/VK** могут требовать авторизацию; публичные ссылки не всегда парсятся. Решение: провайдеры с ключами + ручной ввод.
- **Shazam-совместимый endpoint** нестабилен. Решение: AudD/ACRCloud + ручной поиск.
- **yt-dlp** часто меняется. Решение: обновление из настроек, понятная ошибка, логи.
- **Android фон** требует нативного кода; WebView один не справится. Решение: ExoPlayer-плагин.
- **Медиа-клавиши Windows** – отдельный нативный хук; в MVP могут не работать.
- **Большие библиотеки** – виртуализация списков и ленивые обложки; иначе UI тормозит.
- **Кириллица в путях** – тестировать на `C:\Users\keytom\Another\GnH\Music`; Rust/JS UTF-8.

## 17. Что решено, а что оставлено

Решено: B, Nova, тёмная тема, янтарь, два аудиодвижка, локальное чтение, скрытие вместо удаления, подтверждение загрузок, yt-dlp + AudD/ACRCloud + встроенное распознавание.

Оставлено мастеру: точная сетка экранов, анимации, пустые состояния, тексты ошибок, порядок колонок в таблицах, выбор библиотеки для виртуализации.

Ожидает ответа: финальный вариант «тающего колокола» (см. `docs/design/nova-icons.html`).
