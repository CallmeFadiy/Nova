### Важно про GPL

Встроенное распознавание использует `songrec-lib` (GPL-3.0+), а Android-сборка
включает `youtubedl-android` и его ffmpeg/Python-payload (см. раздел
«Android»). Если вы распространяете собранное приложение с этими
зависимостями, на комбинированную работу распространяется GPL-3.0: нужно
предоставить исходники (включая скрипты сборки GPL-компонентов), тексты
лицензий и предложение получить исходники. Nova уже распространяется под
GPL-3.0 (корневой `LICENSE`), поэтому лицензии совместимы; для APK это
означает, что получатель должен иметь возможность получить полный
соответствующий исходный код и тексты лицензий, а не только бинарник.

Если нужна более свободная лицензия, есть два пути:

1. Оставить только AudD/ACRCloud (убрать `songrec-lib`).
2. Вынести `songrec-lib` в отдельный GPL-sidecar и общаться с ним по файлу/JSON, не линкуя библиотеку в основной бинарник.

Для личного использования без публикации это не критично.

## Android

| Компонент | Лицензия | Зачем |
|-----------|----------|-------|
| `io.github.junkfood02.youtubedl-android:library:0.18.1` | GPL-3.0 (объявлена в POM артефакта) | встроенный загрузчик: Python 3.12 runtime и `yt-dlp` zipapp |
| `io.github.junkfood02.youtubedl-android:ffmpeg:0.18.1` | GPL-3.0 (POM; бинарник собран с `--enable-gpl --enable-version3`) | `ffmpeg`/`ffprobe` для `-x --audio-format mp3` |
| Python 3.12 runtime (в `library-0.18.1.aar`) | PSF-2.0 (лицензия Python; текст в AAR не поставляется) | запуск `yt-dlp` |
| `yt-dlp` 2025.11.12 (zipapp в `library-0.18.1.aar`) | Unlicense (лицензия исходного проекта yt-dlp) | загрузка YouTube и прямых ссылок |

POM-файлы `library` и `ffmpeg` декларируют `GPL-3.0 license`; отдельного
`LICENSE`/`COPYING` в AAR нет. Бинарник ffmpeg сообщает конфигурацию
`--enable-gpl --enable-version3` и включает GPL-компоненты (например,
`libx264`, `libx265`), то есть распространяется как GPL-3.0. Python 3.12 и
yt-dlp сохраняют собственные лицензии; их тексты нужно добавить в notices
распространяемого APK.

## Источники метаданных и аудио

- Deezer API – публичные плейлисты и превью 30 секунд.
- Zaycev.net, Muzofond.fm, DriveMusic.me – публичный поиск и прямые ссылки, которые отдают сами сайты.
- YouTube: метаданные одиночного видео через noembed; загрузка через `yt-dlp`.
- Яндекс Музыка: публичный список треков плейлиста через API; аудио через `yt-dlp`.
- Genius – поиск и текст песни для кэша.
- Shazam-совместимый сервис через `songrec-lib` – распознавание.
- AudD – по ключу пользователя.
- Spotify / Apple Music / VK – только метаданные и ссылки, без обхода DRM.

Nova не обходит DRM. Скачивание выполняется из источника, который выбрал пользователь, и только для контента, на который у него есть права.
