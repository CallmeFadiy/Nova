### Важно про GPL

Встроенное распознавание использует `songrec-lib` (GPL-3.0+). Если вы распространяете собранное приложение с этой зависимостью, на комбинированную работу распространяется GPL-3.0: нужно предоставить исходники и текст лицензии.

Если нужна более свободная лицензия, есть два пути:

1. Оставить только AudD/ACRCloud (убрать `songrec-lib`).
2. Вынести `songrec-lib` в отдельный GPL-sidecar и общаться с ним по файлу/JSON, не линкуя библиотеку в основной бинарник.

Для личного использования без публикации это не критично.

## Источники метаданных и аудио

- Deezer API – публичные плейлисты и превью 30 секунд.
- Zaycev.net, Muzofond.fm, DriveMusic.me – публичный поиск и прямые ссылки, которые отдают сами сайты.
- YouTube: метаданные одиночного видео через noembed; загрузка через `yt-dlp`.
- Яндекс Музыка: публичный список треков плейлиста через API; аудио через `yt-dlp`.
- Genius – поиск и текст песни для кэша.
- Shazam-совместимый сервис через `songrec-lib` – распознавание.
- AudD – по ключу пользователя.
- Spotify / Apple Music / VK – только метаданные и ссылки, без обхода DRM.

Nova не обходит DRM. Скачивание выполняется из источника, который выбрал пользователь, и только для контента, на который у него есть права.
