# Решения по проекту

## Продукт

- Локальный медиаплеер для Windows и Android, интерфейс на Tauri 2 + React + TypeScript.
- Основной сценарий: своя музыка в папках, плейлисты из разных папок, избранное, очередь, эквалайзер.
- Первая версия — десктопная (Windows). Android подключается отдельным этапом.

## Жёсткие правила

1. **Сначала десктоп.** Пока пользователь не скажет «делай Android», собираем и проверяем только Windows-версию.
2. **Когда Android начат — собираем обе платформы вместе.** Любое изменение после этого проверяется и на Windows, и на Android. Это правило действует до конца проекта.
3. **Удаление из альбома — только на уровне приложения.** Файл на диске не удаляется. Скрытые треки хранятся в базе и не возвращаются при сканировании без явного «восстановить».
4. **Локальная библиотека — источник истины.** Ссылки, скачивание и Shazam — дополнения, а не замена папкам.
5. **Никакого обхода DRM и платных подписок.** Импорт ссылок Spotify/Apple Music/Яндекса/VK — это разбор метаданных и поиск, а не извлечение защищённого аудио. Скачивание — из источников, которые пользователь добавил сам, и по прямым ссылкам, на контент, на который у него есть права.
6. **Пользователь подтверждает загрузку.** Ни одна найденная песня не скачивается автоматически: сначала список с галочками, потом «Скачать выбранные» или «Скачать всё».
7. **Данные пользователя не покидают устройство** без его действия. Настройки, история, плейлисты и обложки — локально.

## Технические ориентиры

- Метаданные и обложки: Rust-крейт `lofty`; кэш обложек в локальной папке приложения.
- Десктопное аудио: HTMLAudioElement + Web Audio API (BiquadFilter) для эквалайзера.
- Android-аудио: нативный ExoPlayer + foreground service + MediaSession; JS управляет через Tauri-плагин. Это нужно для фона и audio focus.
- Внешние аудио/видео на Android: AudioFocus + `ACTION_VIEW` intent-фильтры; пауза при потере фокуса, возобновление после `AUDIOFOCUS_GAIN`.
- Сканирование: при старте + вручную; инкрементальное по mtime/size, чтобы не перечитывать всё.
- Очередь и «перемешать»: сохраняемый порядок, отображается в панели очереди; повтор одного трека — отдельный режим.
- Состояние сессии: последний плейлист/очередь и последний трек восстанавливаются при запуске.

## Реализовано в десктопной версии

- SQLite + `lofty`, инкрементальный скан, обложки в `%APPDATA%\com.fadiy.nova\covers`.
- Web Audio + `HTMLAudioElement`, 10-полосный эквалайзер, asset protocol с динамическим allowlist папок.
- Поиск Zaycev/Muzofond/DriveMusic с выбором лучшего битрейта, yt-dlp sidecar для полных треков, импорт Deezer/YouTube/Яндекс Музыки.
- Плоские альбомы по каноническому исполнителю; фиты и совместные проекты вынесены отдельно.
- Тексты песен с Genius и файловым кэшем в `%APPDATA%\com.fadiy.nova\lyrics`.
- Встроенное Shazam-распознавание через `songrec-lib` (GPL-3.0+) и AudD по ключу.
- Windows MSI/NSIS-установщики; `npm run build` всегда пересобирает портативный exe.

## Лицензионное следствие

`songrec-lib` распространяется под GPL-3.0+. Пока он слинкован с приложением, публичная сборка Nova должна соблюдать GPL-3.0. Для личного использования это не критично. Если нужна другая лицензия — убрать встроенное Shazam (оставить AudD) или вынести `songrec-lib` в отдельный sidecar. Подробности: `docs/THIRD_PARTY.md`.

## Android

Android ещё не начат. Когда пользователь скажет «делай Android», каждый следующий релиз собирается и проверяется на Windows и Android одновременно.
