# Windows release

Сборка одной командой:

```powershell
npm.cmd run build
```

Скрипт `scripts/build-windows.ps1` запускает `tauri build`, затем копирует
готовые файлы в `release/Windows/` и заново собирает портативный архив.
Веб-версию без exe можно собрать через `npm.cmd run build:web`.

Готовые файлы:

- `Nova.exe` — портативный запускаемый файл. Его можно скопировать в любую папку и запустить.
- `yt-dlp-x86_64-pc-windows-msvc.exe` — sidecar для скачивания полных треков. Должен лежать рядом с `Nova.exe`.
- `Nova-0.1.0-setup.exe` — обычный установщик (NSIS).
- `Nova-0.1.0.msi` — MSI-установщик.
- `Nova-0.1.0-portable.zip` — архив с `Nova.exe`, `yt-dlp` и краткой инструкцией.

## Портативная версия

Запустить `Nova.exe` двойным кликом. Данные хранятся в `%APPDATA%\com.fadiy.nova`.  
Для скачивания через yt-dlp рядом должен быть `yt-dlp-x86_64-pc-windows-msvc.exe`.  
WebView2 уже входит в Windows 11; на старых системах может потребоваться Microsoft Edge WebView2 Runtime.

## Установщик

`Nova-0.1.0-setup.exe` устанавливает приложение, иконку в меню «Пуск», ярлык и `yt-dlp` sidecar.  
MSI-версия предназначена для организаций и тихой установки.

## Что проверить после установки

1. Запустить Nova.
2. «Добавить папку» → выбрать `Music` или свою папку.
3. Нажать «Сканировать» в правом верхнем углу страницы.
4. Проверить play/pause, next/prev, seek, громкость, очередь, повтор.
5. Открыть «Альбомы»: один исполнитель — одна карточка; совместные треки вынесены отдельно.
6. Открыть «Настройки» → «Эквалайзер», проверить пресеты.
7. «Загрузки» → выбрать папку → найти трек на zaycev.net / muzofond.fm / ru.drivemusic.me → скачать; проверить окно дубликата.
8. Нажать кнопку «Текст песни» в плеере; проверить кэш в «Настройки» → «Тексты песен» и удаление.
9. «Импорт ссылки» → вставить плейлист Яндекс Музыки или одиночное видео YouTube; проверить очередь и прогресс-бар каждой строки.
10. «Распознать трек» → выбрать микрофон или системные динамики, проверить анимацию «Слышу звук» и результат.
11. Правый клик по треку: изменить название/автора, добавить в плейлист, объединить альбомы, удалить трек и файл.
12. «Настройки» → «Уведомления»: прослушать варианты, выбрать звук и нажать «Проверить уведомление».
