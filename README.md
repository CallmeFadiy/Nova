# Nova

Локальный медиаплеер для Windows (и позже Android). Tauri 2 + React + TypeScript, SQLite, всё хранится на устройстве.

**Статус:** десктопная версия собрана и проверена на тестовой библиотеке. Android ещё не начат – по правилу проекта он подключается только по команде, после чего собираются обе платформы.

**Скачать:** [Nova 0.1.0 для Windows](../../releases/latest).

## Что работает

- Сканирование локальных папок при запуске и кнопка ручного сканирования в шапке страниц.
- Метаданные и обложки через `lofty`; фолбэк на имя файла и обложки папки.
- Библиотека, альбомы по исполнителям, папки, поиск, сортировка A–Z / по исполнителю / по альбому / по дате.
- Плоский альбом исполнителя: `Asper X`, `ASPER X` и `Asper_X_-_Sgorayu` объединяются, а `Asper X, Ctrl+Freak` остаётся отдельным проектом.
- Плеер: play/pause, next/prev, seek, громкость, mute, повтор одного трека и очереди.
- Очередь с видимым порядком и перемешиванием; порядок сохраняется.
- Плейлисты из разных папок, избранное как отдельный «альбом».
- «Убрать из альбома» скрывает трек в приложении, файл на диске остаётся.
- Эквалайзер на 10 полос с встроенными и своими пресетами.
- Восстановление последней очереди и трека при запуске (пауза, без неожиданного звука).
- Фоны приложения и экрана «Сейчас играет», затемнение, обложки треков.
- Импорт плейлистов Deezer, YouTube и публичных плейлистов Яндекс Музыки; одиночное видео YouTube разбирается через noembed, если yt-dlp недоступен.
- Поиск по названию/исполнителю через `zaycev.net`, `muzofond.fm` и `ru.drivemusic.me`; лучший доступный битрейт показывается первым.
- Загрузка полных треков через прямые ссылки источников или `yt-dlp` (bestaudio, `--audio-quality 0`) после подтверждения.
- Ручной выбор папки загрузок.
- Текст песни по кнопке: поиск на Genius, кэш в файле с именем трека, список и удаление кэша в настройках. Синхронизированные LRC-тексты: редактор привязки строк к времени, сдвиг на ±0,5 с и автоскролл активной строки.
- Встроенное Shazam-распознавание (12 секунд с микрофона или системного звука через WASAPI loopback) и AudD по ключу; живая анимация уровня, выбор источника в настройках.
- Импорт плейлистов с очередью загрузок: при недоступности исходника трек ищется на Zaycev/Muzofond/DriveMusic, у каждой строки свой прогресс-бар.
- Предупреждение о дубликатах: «Не скачивать», «Скачать и заменить», «Скачать всё равно»; окно привязано к нажатой кнопке, а не к центру длинного списка.
- Проверка дубликатов по SHA-1: в группу попадают только файлы с одинаковым содержимым. Пользователь сам отмечает, какие копии удалить, может оставить несколько или нажать «Не трогать» для группы.
- Защита загрузок от чужого трека: кандидат сверяется с исполнителем и названием, а теги скачанного файла проверяются ещё раз. Если источник отдал другую песню, файл удаляется и показывается ошибка.
- Темы Nocturne, «Лёд», «Огонь», «Пепел», «Киберпанк» отличаются материалами, рамками, узорами и акцентами, а не только палитрой; подтверждения и уведомления оформлены в стиле приложения.
- Перемотка трека доступна и на нижней панели, и на главной карточке «Продолжить слушать».
- С главной карточки можно переключить воспроизведение с текущего альбома на всю библиотеку.
- Альбомы оформлены как Polaroid-карточки: бумажная рамка, лента, лёгкий наклон, подпись и разный материал для каждой темы.
- «Текущие загрузки» показывает активную загрузку и очередь ожидающих файлов; завершённые и ошибочные не засоряют список.
- Управление очередью загрузок: пауза/продолжение, отмена ожидающих, изменение порядка и повтор ошибок. История загрузок хранится отдельной вкладкой с открытием папки и повтором.
- Очистка отсутствующих записей: в настройках показывается количество `missing`-записей и кнопка удаления только этих записей без затрагивания диска.
- Исправление кодировки тегов: предпросмотр cp1251/UTF-8-кракозябр и применение исправлений к метаданным в базе; сканер применяет то же исправление при следующих сканированиях.
- Рекомендация в группе дубликатов выбирается по формату и битрейту, но предупреждение и ручное подтверждение удаления сохраняются.
- Удаление трека убирает его из текущей очереди; если удалён играющий трек, включается следующий, а не очищается вся очередь.
- Shift+Click выделяет диапазон треков, Ctrl/Cmd переключает отдельные строки; массовые действия «В плейлист» и «Удалить».
- Редактирование названия, исполнителя, альбома и album artist; объединение альбомов с новым именем.
- Контекстное меню по правому клику: плейлист, текст, редактирование, объединение, удаление трека вместе с файлом.
- Уведомления в теме Nova с выбором одного из четырёх синтезированных звуков и предпрослушиванием.
- Windows-установщики MSI и NSIS; портативный exe пересобирается при каждой сборке.

## Сборка

```powershell
# dev
npm.cmd install
npm.cmd run tauri dev

# production: exe + portable zip + MSI + NSIS
npm.cmd run build
```

`npm.cmd run build` всегда запускает `tauri build`, копирует `Nova.exe`,
установщики и `yt-dlp` в `release/Windows/` и заново собирает портативный
архив. Для одной только веб-части используйте `npm.cmd run build:web`.

Готовые установщики:

- `release/Windows/Nova-0.1.0-setup.exe` – установщик NSIS
- `release/Windows/Nova-0.1.0.msi` – MSI
- `release/Windows/Nova.exe` – портативный exe
- `release/Windows/yt-dlp-x86_64-pc-windows-msvc.exe` – sidecar для загрузок

Подробнее: `docs/RELEASE.md`.

Для сборки нужны Rust MSVC, Visual Studio Build Tools с C++ и Windows SDK. `yt-dlp` лежит в `src-tauri/binaries/` и входит в установщик.

## Данные

- `Music/` – тестовая библиотека.
- SQLite: `%APPDATA%\app.nova.player\nova.db`
- Обложки: `%APPDATA%\app.nova.player\covers`
- Фоны: `%APPDATA%\app.nova.player\backgrounds`
- Тексты песен: `%APPDATA%\app.nova.player\lyrics\Artist - Title.txt`
- Настройки интерфейса и очередь: `localStorage` WebView.

## Ограничения

- Встроенное Shazam использует `songrec-lib` под GPL-3.0+ (см. `docs/THIRD_PARTY.md`).
- ACRCloud пока не подключён: нужны host, access key и secret.
- YouTube в тестовой сети недоступен для медиапотоков; импорт одиночного видео проверяется через noembed. Яндекс Музыка даёт список треков без авторизации; если источник не отдаёт файл, Nova ищет трек на Zaycev/Muzofond/DriveMusic. Для системного распознавания нужен активный вывод звука Windows.
- Медиа-клавиши Windows и системный трей ещё не сделаны.
- Очень большие библиотеки (десятки тысяч треков) потребуют виртуализации списков.
- Android-версия, фон, audio focus и внешние интенты – следующий этап по команде.
