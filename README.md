# GnH Music

Локальный медиаплеер для Windows и Android. Ядро — Tauri 2 + React + TypeScript, интерфейс на русском, библиотека хранится на устройстве.

**Статус:** этап выбора дизайна. Код приложения ещё не начат — сначала утверждаем направление, имя и иконку.

## Что уже есть

- `Music/` — тестовая библиотека из четырёх треков.
- `docs/design/mockups/` — три HTML-макета главного экрана (1440 × 900).
- `docs/design/screens/` — PNG-снимки макетов.
- `docs/design/names.md` — варианты названия.
- `docs/design/icons.html` — четыре эскиза иконки в разных размерах.
- `icon-design/` — SVG-мастера иконок 1024 × 1024.
- `icon-design/brief.md` — обоснование концепций.

## Направления

## План

1. Утвердить направление, имя, иконку и правила загрузки/Shazam.
2. Собрать десктопную версию: сканирование папок, библиотека, плейлисты, избранное, плеер, очередь, эквалайзер, настройки.
3. Добавить импорт ссылок, поиск и загрузку, распознавание Shazam.
4. Собрать Android-версию: фон, audio focus, внешние интенты, медиа-сессия.
5. Упаковка Windows и Android, проверка на реальной библиотеке.
