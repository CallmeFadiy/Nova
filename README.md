# Nova

Локальный медиаплеер для Windows и Android. Ядро — Tauri 2 + React + TypeScript, интерфейс на русском, библиотека хранится на устройстве.

**Статус:** выбрано направление **B · Sonora**, имя **Nova**, иконка — «тающий колокол». Дизайн-документ на утверждении: `docs/specs/2026-10-25-nova-design.md`.

## Что уже есть

- `Music/` — тестовая библиотека из четырёх треков.
- `docs/specs/2026-10-25-nova-design.md` — дизайн и архитектура.
- `docs/design/mockups/b-nocturne.html` — выбранный макет главного экрана (1440 × 900).
- `docs/design/screens/b-nocturne.png` — снимок выбранного макета.
- `docs/design/nova-icons.html` — три «тающих» варианта иконки.
- `docs/design/names.md` — варианты названия.
- `icon-design/` — SVG-мастера иконок 1024 × 1024.

## Направление

Тёмный кинематографичный интерфейс: графит `#0B0B0D`, янтарь `#D9A441`, Playfair Display + Manrope. Большая обложка, постоянный плеер внизу, панель очереди, эквалайзер.

Архивные направления A и C сохранены в `docs/design/mockups/` для истории.

## План

1. Утвердить дизайн-документ и вариант иконки.
2. Собрать десктопную версию: сканирование папок, библиотека, плейлисты, избранное, плеер, очередь, эквалайзер, настройки.
3. Добавить импорт ссылок, поиск и загрузку через yt-dlp, распознавание (встроенное + AudD/ACRCloud).
4. Собрать Android-версию: фон, audio focus, внешние интенты, медиа-сессия. С этого момента собираем обе платформы вместе.
5. Упаковка Windows и Android, проверка на реальной библиотеке.
